Latest validation run

Full SPARC sweep, corrected pipeline (Oct 18, 2026) — 175 galaxies, 3,391 data points, per-galaxy least-squares fits, Newton + MOND baselines on identical data. Reduced χ² ≈ 1.0 is the ideal; SPARC's tiny formal errors keep every model above it, so read this head-to-head:

QAG

5.55 (median 1.42)

Reduced χ² across 175 galaxies. Wins 167/175 vs MOND, 170/175 vs Newton.

MOND

56.55

Standard MOND, fixed a₀ = 1.2×10⁻¹⁰ m/s² — 10× worse than QAG.

Newton

616.74

Baryons only, no dark matter — 111× worse than QAG.

ΔBIC (MOND−QAG) = 172,054: decisive. Methods, per-galaxy tables, and the audit that caught the old circular formula — all public.
