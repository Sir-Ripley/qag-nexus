The empirical conflict

In spiral and gas-dominated dwarf galaxies (DDO 154, NGC 3198, UGC 128), Newtonian gravity predicts rotation speeds should fall as v ∝ r−1/2 beyond the optical disc. Observed curves stay flat for tens of kiloparsecs. Standard astrophysics reconciles this with invisible Cold Dark Matter halos — 2–3 free parameters fitted per galaxy — yet no dark matter particle has been detected after decades of multi-billion-dollar searches.

Section 1 · The consensus model

ΛCDM halo fitting & the empirical RAR

In ΛCDM, galaxies sit inside vast collisionless dark matter halos. Observed velocity is the Pythagorean sum of baryons plus halo:

\[v_{obs}^2(r) = \Upsilon_\star\,v_{disk}^2(r) + \Upsilon_\star\,v_{bulge}^2(r) + v_{gas}^2(r) + v_{halo}^2(r)\]

Two workhorse halo profiles:

\[\rho_{ISO}(r) = \frac{\rho_0}{1 + (r/r_c)^2}\qquad\text{(pseudo-isothermal)}\]

Each galaxy gets its own ρ₀ and rc — fitted, not predicted. The framework works, but it explains flat curves by adding invisible mass tuned galaxy-by-galaxy.

Section 3 · Python verification

Run it yourself

Paste this into any Python environment with numpy and matplotlib. It loads DDO 154's SPARC data, computes all three models, and prints the reduced χ² shootout:

import numpy as np import matplotlib.pyplot as plt r = np.array([0.24,0.48,0.72,0.96,1.20,1.44,1.92,2.40,2.88,3.84,4.80,5.76,6.72]) v_o = np.array([10.5,17.2,22.4,26.8,30.3,33.7,38.6,42.1,44.8,48.0,49.5,50.8,51.2]) v_e = np.array([2.0,2.0,2.0,1.8,1.8,1.8,2.0,2.2,2.3,2.5,2.5,2.5,2.8]) v_disk = 8.5 * (r/(r+1.2)); v_gas = 25.0*np.sqrt(r/(r+1.8)) v_bary = np.sqrt(0.10*v_disk**2 + v_gas**2) # Upsilon Lock r_c, v_hmax = 1.25, 44.0 # consensus halo v_halo = v_hmax*np.sqrt(1-(r_c/r)*np.arctan(r/r_c)) v_lcdm = np.sqrt(v_bary**2 + v_halo**2) v_inf, r_aff = 47.8, 2.54 # QAG AVI Law v_qag = np.sqrt(v_bary**2 + v_inf**2*(1-np.exp(-r/r_aff))) dof = len(r)-2 print("LCDM chi2/nu:", np.sum(((v_o-v_lcdm)/v_e)**2)/dof) print("QAG chi2/nu:", np.sum(((v_o-v_qag)/v_e)**2)/dof) plt.errorbar(r, v_o, yerr=v_e, fmt='ko', label='SPARC DDO 154') plt.plot(r, v_bary, 'g--', label='Newtonian baryons') plt.plot(r, v_lcdm, 'b-.', label='Pseudo-isothermal halo') plt.plot(r, v_qag, 'r-', lw=2.5, label='QAG AVI Law') plt.xlabel('r (kpc)'); plt.ylabel('v (km/s)'); plt.legend(); plt.show()
